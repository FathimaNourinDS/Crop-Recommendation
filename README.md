# Crop-Recommendation
A simple machine learning project that predicts the best crop based on soil and weather parameters. Built using Python and scikit-learn.


# Features

>Predicts recommended crop using soil nutrients (N, P, K) and environmental factors (temperature, humidity, pH, rainfall).
>Preprocessing with StandardScaler and LabelEncoder.
>Easy to use and extend for predictions.


# Technologies

>Python 3.x
>Pandas & NumPy
>scikit-learn
>pickle (for saving models)
>Google Colab
